CÂU HỎI 2a

Định vị tính năng Đăng nhập & Ràng buộc có dấu @

1. File xử lý logic: app/Controllers/AuthController.php (Hàm register() và login()).

2. File xử lý CSDL: app/Models/UserModel.php (Mã hóa bcrypt bằng password_hash()).

3. File giao diện: app/Views/login.php.

// Thêm ràng buộc mật khẩu có dấu @ (Server)

}
CÂU HỎI 2c

Vai trò Leader: Đánh giá qua Git Log & Diff

1. Không đếm số dòng code (LOC): Đếm dòng code là sai lầm vì dễ bị gian lận (copy thư viện, format bừa bãi).

2. Đánh giá qua `git log`: Kiểm tra Atomic Commits (mỗi commit giải quyết trọn vẹn 1 tính năng/bug), thông điệp rõ ràng (feat:, fix:), tiến độ làm việc đều đặn.

3. Đánh giá qua `git diff`: Code có tập trung đúng phạm vi task không, có để lại rác debug (var_dump) không, tỉ lệ sửa lại bug (code churn) có thấp không.
